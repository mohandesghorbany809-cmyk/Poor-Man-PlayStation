🚨 WARNING: This repository may cause unexpected gaming sessions, questionable life decisions, and the sudden urge to say, "Bro, I can make a game too!"

🎮 What's Inside?

- 🕹️ A collection of crazy little HTML games.
- 💻 Games built with code, creativity, and questionable amounts of sleep.
- 😂 Unexpected moments, chaotic gameplay, and ideas that escaped directly from my brain.
- 🧠 Proof that you don't need a million-dollar studio to start making something fun.

👨‍💻 The Developer: AmirAli Ghorbani — aka Midnight Coder 🌙

- No expensive console? CODE IT.
